# BioCraft

> **The Cellular Biology & Genetics Sandbox** (`com.royals.biocraft`)

BioCraft is an interactive 3D cellular biology and genetic simulation sandbox application built with React 19, Three.js, Vite, Tailwind CSS, Capacitor, and Unity integration.

---

## 🔬 Overview & Features

- **Cellular Simulation**: Real-time rendering and interactive 3D simulations of cellular components, organelles, and processes.
- **Genetic Engineering Sandbox**: Explore DNA/RNA transcription, translation, and genetic mutations.
- **Cross-Platform**: Web and Android support powered by Capacitor and Android Studio toolchain.
- **Modern Tech Stack**: React 19, Vite, Three.js, Lucide Icons, and Tailwind CSS.

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ssilu07/BioCraft.git
cd BioCraft

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
# Build web app
npm run build

# Preview build
npm run preview
```

### Android Build (Capacitor)
```bash
# Sync Capacitor with Android
npx cap sync android

# Open Android Studio
npx cap open android
```
